**Kalamo Bhala 0.85: Offline Mathematics & LaTeX typesetting, Function Plotter, CAPS geometry & tariff templates, Math Voice, and split-view guide**

Full details: [CHANGELOG](../../blob/main/CHANGELOG.md).

> **Free, provided "as is", without guarantees or warranties of any kind.** Bugs can be expected. Keep your own backups of your writing.
> **Mac and Linux:** Apple Silicon and Linux pass every automated test on real Mac and Linux CI machines, though few writers have used them yet. Mac Intel has no CI machine. Please report what you find in [Issues](../../issues).

**What is new in 0.85:**
- **Mathematics & LaTeX in the Editor:** Typeset beautiful offline formulas with KaTeX. Support for display block equations (`$$` or ````math`) and inline formulas (`$...$`) via the toolbar `∑` button, `/math`, or keyboard shortcuts.
- **Unified Math Commands & Starters:** Access all math workflows directly from `/math` autocomplete (`/math`, `/geometry`, `/graph`, `/tariff`, `/dictatemath`, `/mathguide`), with an equation starter palette (quadratic, trigonometry, geometry, finance, calculus, integrals, matrices).
- **Interactive Function Plotter (/drawgraph):** Insert Cartesian function plots with multiple curves, domain/range scaling, asymptotes, coordinates, turning points, and automatic grid rendering in pure SVG.
- **South African CAPS Curriculum Templates:** Built-in two-column Euclidean Geometry Statement & Reason (`/geometry`) proof tables with angle hats and South African CAPS reasons, plus Municipal Stepped Tariff (`/tariff`) calculation tables with ZAR currency formatting.
- **Math Voice (Read Aloud & Voice-to-Math Dictation):** Read Aloud (`Alt+A`) speaks math equations naturally in plain pedagogical English instead of raw LaTeX. Voice-to-Math (`/dictatemath`) converts spoken formulas into LaTeX with a real-time visual KaTeX preview, manual edit pause toggle, and clean insertion.
- **Comprehensive Math & LaTeX Guide in Split View (/mathguide):** Opens a side-by-side reference manual with searchable snippets, South African CAPS curriculum geometry reasons, and a "+ Save copy to project" button to keep an editable guide in your binder.
- **One-Click Deletion:** One-click `[ Delete ]` buttons on math block, diagram, and graph hover bars, and a `🗑️` button on inline math floating edit pills.
- **Math Export to Word, OpenDocument, e-book & PDF:** Equations export as crisp, centered 2x vector-sharp images in MS Word (.docx), OpenDocument (.odt), and e-book (.epub), and vector-rendered in browser Print to PDF.

**Start:**
- **Windows:** right-click the ZIP → **Extract All…** → double-click **Start Kalamo**. If Windows says *"Windows protected your PC"*: **More info** → **Run anyway**.
- **Mac:** double-click the ZIP, then **Start Kalamo.command**. The first time: System Settings → Privacy & Security → **Open Anyway** (Kalamo is not signed by Apple).
- **Linux:** `tar -xzf Kalamo-Bhala-0.85-Linux-x64.tar.gz`, then `cd "Kalamo Bhala 0.85"` and `./start-kalamo.sh`.

**Updating:** from 0.53 or later, Kalamo shows a pop-up within a week (or Settings → About and reset → **Check now**): **Download and install** on Windows and Mac; on Linux the pop-up opens this page. From 0.51 or 0.52: Quit, unpack this version and start it. Your writing, settings and API keys are kept.

New to Kalamo? Read the [guide](../../blob/main/GUIDE.md).

**Check your download (optional):** each file has a `.sha256` next to it. Windows (PowerShell): `Get-FileHash .\Kalamo-Bhala-0.85-Windows.zip`; Mac/Linux: `shasum -a 256 <file>`.

`latest.json` is the small file Kalamo's weekly update check reads; you do not need to download it.
