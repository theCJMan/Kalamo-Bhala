**Kalamo Bhala 0.70: import, export, voice, pictures, history and much more**

The largest update since launch. Full details: [CHANGELOG](../../blob/main/CHANGELOG.md).

> **Free, provided "as is", without guarantees or warranties of any kind.** Bugs can be expected. Keep your own backups of your writing.
> **Mac and Linux:** Apple Silicon and Linux pass every automated test on real Mac and Linux CI machines, though few writers have used them yet. Mac Intel has no CI machine. Please report what you find in [Issues](../../issues).

**Which file?**
| Your computer | File |
| --- | --- |
| Windows 10 or 11 (64-bit) | `Kalamo-Bhala-0.70-Windows.zip` |
| Mac with Apple Silicon (M1 and later) | `Kalamo-Bhala-0.70-Mac-AppleSilicon.zip` |
| Mac with an Intel processor | `Kalamo-Bhala-0.70-Mac-Intel.zip` |
| Linux, most PCs | `Kalamo-Bhala-0.70-Linux-x64.tar.gz` |
| Linux on ARM (64-bit) | `Kalamo-Bhala-0.70-Linux-ARM64.tar.gz` |

Or use the one-click links on the [README](../../blob/main/README.md) — they always point to the newest version.

**Start:**
- **Windows:** right-click the ZIP → **Extract All…** → double-click **Start Kalamo**. If Windows says *"Windows protected your PC"*: **More info** → **Run anyway**.
- **Mac:** double-click the ZIP, then **Start Kalamo.command**. The first time: System Settings → Privacy & Security → **Open Anyway** (Kalamo is not signed by Apple).
- **Linux:** `tar -xzf Kalamo-Bhala-0.70-Linux-x64.tar.gz`, then `cd "Kalamo Bhala 0.70"` and `./start-kalamo.sh`.

**Updating:** from 0.53 or later, Kalamo shows a pop-up within a week (or Settings → About and reset → **Check now**): **Download and install** on Windows and Mac; on Linux the pop-up opens this page. From 0.51 or 0.52: Quit, unpack this version and start it. Your writing, settings and API keys are kept.

New to Kalamo? Read the [guide](../../blob/main/GUIDE.md).

**Check your download (optional):** each file has a `.sha256` next to it. Windows (PowerShell): `Get-FileHash .\Kalamo-Bhala-0.70-Windows.zip`; Mac/Linux: `shasum -a 256 <file>`.

`latest.json` is the small file Kalamo's weekly update check reads; you do not need to download it.
